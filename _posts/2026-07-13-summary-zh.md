## [sqlite-utils 4.1.1 修复转换中的静默数据丢失](https://simonwillison.net/2026/Jul/12/sqlite-utils/#atom-everything) ⭐️ 7.0/10

sqlite-utils 4.1.1 修补了一个关键边缘情况：在启用 PRAGMA foreign_keys 的打开事务中执行 table.transform() 时，可能因 ON DELETE 操作导致静默数据丢失。 此修复防止了引用行的静默损坏或删除，对于依赖外键约束的应用程序尤其重要。它展示了 sqlite-utils 作为广泛使用的 SQLite 数据库管理 Python 库的细致工程。 该补丁在调用 transform() 时，如果事务中启用了外键且存在破坏性 ON DELETE 操作（CASCADE, SET NULL, SET DEFAULT），会引发 TransactionError。文档现在也交叉引用了 CLI 和 Python API 部分。

rss · Simon Willison · 7月12日 20:55

**背景**: table.transform() 实现了 SQLite 推荐的模式迁移：创建新表、复制数据、删除旧表并重命名。然而，删除旧表可能触发对引用行的 ON DELETE 操作，而 PRAGMA foreign_keys 在事务内无法更改，因此无法禁用这些操作。此版本添加了安全检查以防止这种情况。
